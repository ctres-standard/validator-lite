# Demonstration packages

Two synthetic CTRES v1.0 packages for trying validator-lite. Their values are illustrative, like the examples in Annex C of the Standard. They describe a fictional operator, licence and profile in **XJ**, an ISO 3166-1 user-assigned code used here for a fictional jurisdiction. No value is drawn from any operator, player, provider or authority, and both manifests set `"synthetic": true`.

Both packages are generated by [`scripts/make_demo.py`](../scripts/make_demo.py), which reproduces them byte for byte:

```sh
python scripts/make_demo.py
```
